# บันทึกรายรับรายจ่าย

เว็ปจดรายรับรายจ่ายส่วนตัว พิมพ์ข้อความภาษาไทยแล้วแอปแยกประเภท หมวด จำนวนเงิน และวันที่ให้เอง
ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง และซิงก์ข้ามเครื่องผ่าน Firebase (ล็อกอินด้วย Google) เมื่อตั้งค่า

- `expense-tracker.html` ตัวแอป (ไฟล์เดียว)
- `firebase-config.js` ค่า config ของ Firebase (ไม่ใช่รหัสลับ)
- `firestore.rules` กฎความปลอดภัยของฐานข้อมูล (แต่ละบัญชีอ่านเขียนได้เฉพาะข้อมูลของตัวเอง)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` สำหรับติดตั้งเป็นแอปและใช้ออฟไลน์

ฝากเว็ปที่ Netlify ตั้งให้อัปเดตเองทุกครั้งที่ push ขึ้นสาขา main
